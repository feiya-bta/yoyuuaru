データ移行

① 古い端末：コードをコピー

いまのデータ（支出・予算・カテゴリ・マイルーム）を1つのコードにまとめました。コピーして、メモ・LINE・メールなどで新しい端末に送ってください。

コードが長くてチャットに貼れないときは、ファイルに保存して送ってください。

② 新しい端末：コードを貼り付け

新しい端末は「すべて置き換える」がおすすめです。すでに両方の端末に記録がある場合は「統合」を選ぶと、記録を足し合わせます（マイルームは新しい方が残ります）。

※ レシートの写真と、OCR の API キーはコードに含まれません。コードには家計データがそのまま入っているので、他の人には見せないでください。

貯金プランナー

月収とほしいものの金額を入れると、あと何日で買えるかを計算します。支出は実際の記録から自動で見積もります。

カテゴリ設定

カテゴリ別予算

今月、カテゴリごとに使える金額を決めます。空欄のカテゴリは「決めない」になります。

カテゴリ予算の合計が総予算を超えても保存できます。超えている場合は赤く表示します。

データ管理

設定

バックアップ

記録した支出をCSVファイルとして書き出したり、CSVファイルから読み込んだりできます。

バックアップファイル（端末の引っ越し）

CSV と違い、品目・店舗・予算・部屋の情報まで欠けずに移せます。新しい端末で読み込むと、いまの記録と自動で統合されます（上書きされません）。

データ移行（コードで引っ越し）

データを1つのコードにしてコピーし、新しい端末に貼り付けるだけで移せます。

レシート読み取り（OCR）の設定

自分の APIキー を入れると、レシートを撮影して自動入力できます。キーはこの端末にだけ保存されます。読み取り時のみ、画像が選択した事業者へ送信されます。

マイルームのバックアップ

ポイント・所持アイテム・部屋のレイアウトをCSVで書き出し／読み込みできます。

リセット

今月分の支出と予算だけを消すか、すべてのデータを消して初期状態に戻せます。元に戻せないのでご注意ください。
